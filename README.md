
## Environment Variables

Copy `.env` to `.env.local` and fill in the values:

```env
# Store API authentication (public template — values exposed intentionally for demo/dev)
STORE_API_KEY=sk_live_8cmcxvqsbtt5
PROXY_API_BASE_URL=https://entaprenua.com
VITE_API_PREFIX=/api/v1

# Email (Resend)
RESEND_API_KEY=
EMAIL_FROM=
EMAIL_FROM_NAME=

# OAuth providers
GOOGLE_AUTH_ENABLED=
FACEBOOK_AUTH_ENABLED=
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
FACEBOOK_CLIENT_ID=
FACEBOOK_CLIENT_SECRET=

# Payment providers
# M-Pesa
# MPESA_CONSUMER_KEY=
# MPESA_CONSUMER_SECRET=
# MPESA_SHORTCODE=
# MPESA_PASSKEY=
# MPESA_CALLBACK_URL=
# MPESA_ENVIRONMENT=
# Stripe
# STRIPE_SECRET_KEY=
# STRIPE_CLIENT_ID=

# Google Maps
GOOGLE_MAPS_ENABLED=
GOOGLE_MAPS_API_KEY=
GOOGLE_MAPS_LATITUDE=
GOOGLE_MAPS_LONGITUDE=
```
